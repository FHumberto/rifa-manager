# Rifa Manager

Sistema para gerenciamento interno de rifas.

O projeto tem como objetivo facilitar o controle de rifas, participantes, bilhetes, pagamentos e sorteios em uma aplicação full-stack.

A primeira versão foi desenvolvida para apoiar a organização de um sorteio pontual com finalidade beneficente.

## Stack Planejada

### Backend

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite no MVP
- ASP.NET Core Identity
- FluentValidation
- xUnit
- Shouldly

### Frontend

- Angular
- TypeScript
- PrimeNG
- Angular Router
- Reactive Forms

## Funcionalidades Planejadas

- Autenticacao de usuarios
- Cadastro e gerenciamento de usuarios
- Cadastro e gerenciamento de rifas
- Geracao automatica de bilhetes
- Cadastro de participantes
- Registro de compra de bilhetes
- Controle de pagamento
- Consulta e pesquisa de bilhetes e participantes
- Sorteio com bilhetes pagos
